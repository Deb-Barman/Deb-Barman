## About

I build systems that sit at the intersection of AI agents, multi-provider LLM infrastructure, and rigorous documentation — the kind of engineering that treats a side project with the same discipline as production software: full test suites, encrypted key handling, phased specs, and real architecture instead of scripts glued together.

I work across **Python**, agent frameworks (**Google ADK**, custom orchestration), and the full spread of LLM providers — **NVIDIA NIM, HuggingFace, OpenRouter, Ollama, and the Anthropic API** — because building multi-provider from day one forces you to actually understand the abstractions instead of hard-coding around one vendor's quirks.

Outside of pure engineering, I write and structure large-scale knowledge bases (100+ files, tens of thousands of words, consistent templates), and I work in AI-driven video/photo editing and content production.

## Selected Work

### 🤖 Agent Systems & Orchestration

| Project | What it is |
|---|---|
| **BUTTERFLY** | A 19-module multi-provider AI CLI tool — encrypted key storage, MCP server integration (stdio + SSE), skill importing, and a live Textual split-pane UI. |
| **BLACKCORE** | The cryptographic core behind BUTTERFLY: a dual-file split-secret architecture using XChaCha20-Poly1305, Argon2id (256MB / 6-pass), and HMAC-SHA3-512 — backed by a 38-test suite. |
| **Godfather Agent** | A 100+ agent, 8-tier orchestration framework with a 7-layer memory system, built on Google ADK and Gemini 2.0 Flash. |
| **Chief Executive Agent (CEA)** | A multi-agent decision-making system built on the Anthropic API. |
| **POE** (Python Operating Environment) | A production-grade, Python-only CLI ecosystem — project, file, git, database, monitoring, backup, and plugin management, delivered through a fixed 22-phase architecture-to-release build process. |
